# Як нормування ознак змінює прогноз продажів під час акції

**Євген Севостьянов і Денис Ромаш**

[Кафедра математики Житомирського державного університету імені Івана Франка](https://eportfolio.zu.edu.ua/users/?chair=17&include_laboratory_assistent=true&view_mode=grid).

Програма порівнює два способи нормування ознак у прогнозуванні промопродажів. Стандартне масштабування центрує ознаки й ділить їх на стандартне відхилення. Проєктний метод добирає радіальне перетворення з обмеженням на спотворення оберненого відображення. В обох варіантах градієнтний бустинг використовує ту саму формулу ваг. Самі ваги змінюються, бо залежать від відстаней між нормованими ознаками. [Дані й умови досліду](docs/DATA.md).

Інтегральна умова походить із роботи Є. Севостьянова, В. Таргонського й Н. Ількевич, виконаної за підтримки Національного фонду досліджень України в межах проєкту **2025.02/0010**. Програма використовує цю умову під час вибору перетворення. В обох акціях вона відхилила профіль, який найточніше відтворював бажані квантили. [Теорема 4.3 на arXiv](https://arxiv.org/html/2509.02008v3#S4) · [Математичне пояснення й код відбору](docs/THEORY.md).

На повній історії в обох акціях проєктне нормування покращило прогноз сумарних продажів товару по мережі зі 148 магазинів. Для 797 товарних прогнозів із додатними продажами середня абсолютна відносна похибка (MAPE) знизилася **зі 192,77% до 146,53%**, а кількість прогнозів, що більш ніж удвічі перевищили фактичні продажі, - **з 310 до 244**. На історії за 112 днів загальний MAPE теж зменшився, хоча у другій акції він зріс. Це оцінка всього способу нормування разом із вагами навчальних прикладів.
