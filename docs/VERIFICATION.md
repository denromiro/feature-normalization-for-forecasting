# Як відтворити розрахунки

20 листопада 2026 року експеримент повторили в чистій копії прикладу. З вихідних таблиць заново навчили вісім моделей і порівняли кожен прогноз з еталоном. Усі 88 356 значень збіглися точно. Такий самий результат отримали, коли завантажили збережені моделі й повторно обчислили прогноз. Перевірку виконано в середовищі Windows із Python 3.10.13. Версії бібліотек, параметри розрахунку й контрольні суми коду записано у протоколі. [Результат перевірки](../results/validation.json) і [протокол запуску](../results/protocol.json).

Для порівняння моделей важливі продажі товару по мережі. Тому магазинні прогнози й фактичні продажі ще раз незалежно підсумували за товарами. Збіглися і самі суми, і всі 12 оцінок MAPE. Це результати обох методів для короткої й повної історії. Для кожного варіанта MAPE обчислили окремо за кожною акцією та за обома акціями разом. [Перевірка товарних підсумків](../results/product_error_checks.json).

Кандидатів можна перевірити без навчання моделей. У файлах профілів поле `radial_loss` містить відхилення від бажаних радіусів, а `feasible` показує, чи пройшов профіль перевірку. Порівняйте мінімум `radial_loss` серед усіх кандидатів і серед допущених. [Математичне пояснення та числова перевірка](THEORY.md) · [Травневі профілі](../results/2026-05-28_candidates.csv) · [Червневі профілі](../results/2026-06-11_candidates.csv).

## Як повторити дослід

Для перевіреного середовища Windows потрібен Python 3.10. У PowerShell відкрийте каталог прикладу й виконайте команди

```powershell
py -3.10 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -X utf8 run_experiment.py
```

У Linux та macOS еквівалентний запуск має такий вигляд

```bash
python3.10 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -X utf8 run_experiment.py
```

Програма навчає моделі й записує звіт нового запуску в `outputs/report.html`. Матеріали перевіреного запуску зберігаються в `results/`, а числові еталони - у `reference/`. Контрольна сума в протоколі належить стисненому файлу прогнозів конкретного запуску. Еталонні файли мають власні контрольні суми. [Контрольні суми даних](../data_manifest.json) та [еталонів](../reference_manifest.json). Склад архіву й результати перевірки його вмісту наведено в [маніфесті](../PACKAGE_MANIFEST.json) та [протоколі перевірки комплекту](../results/package_checks.json).

Діаграми можна відтворити окремо за еталонними прогнозами з комплекту. Скрипт `make_product_error_distribution.py` будує розподіл похибок товарних підсумків, а `make_error_distribution.py` - прогнозів окремих магазинів. Для HTML достатньо запустити відповідний скрипт у тому самому середовищі. Щоб також зберегти рисунки у форматі PNG, у Windows виконайте такі команди

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-visuals.txt
.venv\Scripts\python.exe -X utf8 make_product_error_distribution.py --png
.venv\Scripts\python.exe -X utf8 make_error_distribution.py --png
```

У Linux та macOS у цих трьох командах шлях до Python має вигляд `.venv/bin/python`. Діаграми зберігаються в `results/`. [Розподіл похибок товарних підсумків](../results/product_error_distribution.html) і [розподіл похибок окремих магазинів](../results/error_distribution.html).
